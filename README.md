# PokeEMC

> **让宝可梦世界拥有等价交换的无限可能。**

基于「等价交换」理念、面向 **Pixelmon（像素宝可梦重铸）** 的 NeoForge 附属模组：保留最简约的 EMC 经济，加入**交易系统、远程仓储与购物车**，为生存与收集流程带来全新体验。

[![NeoForge](https://img.shields.io/badge/NeoForge-1.21.1-blue)](#)
[![Version](https://img.shields.io/badge/version-1.0.0--beta.1-orange)](#)

---

## 特性一览

- 🪙 **交易与购物车** — 交易所三栏界面、目录式交易、批量买入与背包一键出售、钱包余额自动同步、购物车集中结算
- ⚡ **最简约的等价交换** — EMC 价值体系、能量凝聚器、转化桌 & 便携转化桌
- 📦 **远程仓储与权限** — 远程浏览所有箱子/潜影盒/凝聚器、搜索排序、半径扫描、批量操作
- 🔒 **仓储保护** — 认领后防破坏/防爆炸/防活塞搬运；双箱被拆一半认领记录自动迁移，不丢归属
- 🔑 **权限分享（ACL）** — 把查看/存入/取出/管理权限精确分享给朋友
- 🤝 **玩家交易（测试中）** — 玩家间面对面交易已进入测试，仍在完善

## 安装

1. 安装 **NeoForge 1.21.1** 并启动一次生成必要目录；
2. 安装 **Pixelmon** 到 `mods` 文件夹；
3. 将 **PokeEMC** 的 `.jar` 放入 `mods` 文件夹；
4. 启动游戏，进入世界后即可使用。

推荐搭配的客户端优化/辅助模组清单见 [`docs/CLIENT_MODS_LIST.md`](docs/CLIENT_MODS_LIST.md)（可选）。
