# PokeEMC 客户端模组清单（NeoForge 1.21.1）

> 本文档整理 **PokeEMC 推荐搭配的客户端模组**。清单**不含** PokeEMC 本体与宝可梦主模组 Pixelmon —— 两者是游玩基底，已默认安装。
>
> - **加载器**：NeoForge，**游戏版本**：1.21.1
> - **纯客户端**：全部为客户端模组（联机进服即可用，无需服务端安装）
> - **不含光影**：1.21.1 光影加载器为 Iris（NeoForge 版），如需光影请自行加装 Iris + 光影包；若追求与 Pixelmon 渲染的最大稳定，建议先跑通本文档清单再叠加光影
> - **下载**：一律在 **CurseForge / Modrinth** 搜索下方「模组名」并选择 **`1.21.1` + `NeoForge`** 的版本文件；文件版本号会持续更新，以平台页面为准
> - **版本核对**：安装后若报缺前置/不兼容，先确认下载的是 NeoForge 版而非 Forge/Fabric 版

## 一、性能优化

| 模组 | 作用 | 建议 |
|---|---|---|
| **Embeddium** | Sodium 的 Forge/NeoForge 移植版，重写区块渲染，FPS 明显提升（典型约 2 倍） | ✅ **必装**。与 OptiFine 二选一，不可共存 |
| **Embeddium Extra** | Embeddium 附属，提供动画/粒子/细节等更多渲染开关 | ✅ 建议 |
| **ModernFix** | 加快加载、降低内存占用、修复大量卡顿/启动问题 | ✅ 建议，重整合包尤其有效 |
| **FerriteCore** | 纯内存优化，削减方块状态/模型内存，无玩法改变 | ✅ 建议，可与 ModernFix 共存 |
| **Distant Horizons** | 远视距 LOD 渲染，视距远超原版且不吃帧 | ⚠️ **可选**。有低概率启动崩溃报告，且与相机类模组冲突；内存分配建议 ≥6G |

## 二、物品管理 / 配方

| 模组 | 作用 | 建议 |
|---|---|---|
| **JEI（Just Enough Items）** | 经典物品/配方查看器（悬停+R 查配方、+U 查用途、搜索/收藏） | ✅ 二选一为主 |
| **EMI** | 现代物品/配方管理器，功能更全（配方树、合成收藏、智能分解） | ✅ 与 JEI 同时安装时 EMI 接管界面、共享配方；用不惯再换回 JEI |
| **Too Many Recipe Viewers**（可选） | JEI/REI/EMI 的配方面板加速 | ➖ 可选，性能向 |

## 三、背包与界面辅助

| 模组 | 作用 | 建议 |
|---|---|---|
| **Inventory Sort-NF** | **R 键一键整理**物品栏/容器（R键整理，NeoForge 1.21.1 移植版） | ✅ **R 键整理**首选，按键可在设置里改 |
| **Mouse Tweaks** | 鼠标拖拽快速转移/均分物品（LMB 拖整组、RMB 均分、滚轮转移） | ✅ 建议，仓储党体验大幅提升 |
| **Controlling** | 按键设置可搜索、按名称/按键筛选，避免键位冲突 | ✅ 建议 |
| **Just Zoom**（或同类缩放模组） | 望远镜式平滑缩放（不装 OptiFine 时的替代） | ➖ 可选，看细节/查看时用 |

## 四、连锁挖掘

| 模组 | 作用 | 建议 |
|---|---|---|
| **VeinMine** | 一键连锁挖掘整条矿脉，可配挖掘范围/方块黑名单，默认 `~` 键开关 | ✅ 轻量首选，支持 NeoForge 1.21 |
| **Universal Vein Miner** | 潜行触发连锁，自动识别矿石，工具耐久保护，尊重时运/精准采集 | ✅ 备选，NeoForge 1.21.1 专用 |

> ⚠️ **Pixelmon 提醒**：连锁挖掘请务必开启**方块白名单/黑名单**，避免连锁破坏宝可梦雕像、彩蛋等特殊方块；`FTB Ultimine` 功能更全但更重，酌情选用。

## 兼容性注意

1. **Pixelmon 兼容**：清单以主流、轻量的客户端模组为主，与 Pixelmon 兼容良好。安装后**首次进入请用现有存档验证**：渲染正常、宝可梦/箱子/交易所界面正常再继续。
2. **OptiFine 冲突**：Embeddium 与 OptiFine 互不兼容，二选一（推荐 Embeddium）。
3. **光影**：本清单未列光影。如需光影，安装 **Iris（NeoForge 1.21.1）** 与光影包；叠加后请留意与 Pixelmon 的兼容与显存占用。
4. **连锁挖掘**：务必配置方块白名单/黑名单后再使用，保护 Pixelmon 特殊方块。
5. **Distant Horizons**：有低概率启动崩溃报告，安装后若启动失败先移除它排查；建议同时提高 `-Xmx` 内存并改用 ZGC（见其官方说明）。
6. **版本核对**：所有模组请选择 **1.21.1 + NeoForge** 版本，版本不匹配会导致启动失败。
7. **少即是多**：优化/辅助类模组并非越多越好。先装「必装 + 建议」部分稳定游玩，再按需添加可选模组。
