建议的核心用户路径

1. 浏览
搜索、分类、排序、悬停查看双价。
2. 购物车
显示容量、种类、总件数、总价，支持逐格和整车清空。
3. 出售预览
显示来源、数量、预计收入、跳过原因，再确认提交。
4. 结果同步
成功清理购物车，失败保留草稿，仓储出售后刷新快照。
